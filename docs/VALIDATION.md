The private publication is an operational demonstration, not approval to accept live customers.

Verified locally: database migration applied successfully, homepage and event pages render against seeded D1 data, desktop hero screenshot reviewed, cookie essential-only control dismisses correctly, event link navigates to its detailed booking form, TypeScript and production build checks performed. Browser logs contained extension messaging errors, with no application errors observed in those inspected pages.

Not yet end-to-end verified: live Stripe payments and refunds, transactional email delivery, hosted sign-in and every administrative workflow, mobile browser interactions, concurrency/load tests, formal accessibility audit, Lighthouse performance audit. These require further verification before public sales. No Lighthouse score or complete security certification is claimed.

All dates, inventory and availability are demonstration data. Food imagery is labelled illustrative; reference images and licence attribution are documented. Real legal content, allergen declarations, founder photographs, venue details and providers are required before launch.
